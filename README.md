## 10Gbps 端口到底能跑多快：实测数据和两个反直觉的点

10Gbps 是端口规格，官方页面也没有承诺每台 VPS 能长期独享这个速率，实际速度受宿主机负载、网络拥塞和线路影响。一套较新的第三方实测（vps小学生，东京机房 AMD + 10Gbps 套餐，黑五期间购入）给出的参考是：电信下载多在 4Gbps 左右、联通约 2.5Gbps、移动波动较大，上传在 100M 到 1.5Gbps 之间；到国内延迟 74ms，三网往返直连。同机硬件表现不错：Ryzen 9 5950X、NVMe 4.0 硬盘平均读写 2GB/s。

有两个点值得单独提醒：

1. **IP 归属可能反直觉**。实测机器的 IPv4 以 43 开头，被流媒体平台判定为美国原生 IP，能解锁美区 Netflix，解锁的流媒体不算少，但 IPv6 不支持解锁 Netflix。你买的是日本机房，拿到的却可能是「美国属性」的 IP——如果你的用途（比如 TikTok 运营、本地化服务）对 IP 归属地敏感，这一点比带宽更值得先确认。
2. **百兆带宽看 4K 没问题**。同一套测试里，100M 移动带宽下手动装了原生 BBR 后，4K 视频播放速度在 7 万以上。对个人用户来说，750GB 月流量才是更先碰到的天花板，不是带宽。

**这个套餐是不限流量的吗？**
不是。$25/年 档是 750GB 月流量，$35 档 1TB，$68 档 2TB，超出部分的处理方式以订单页条款为准。真正接近「不限」的是英国考文垂机房（同价位 3TB 起），但那对国内访问没有意义。

**续费价格是多少？**
官方页面没有单独标注这批特价套餐的续费价，下单页显示的金额为准。这类售完即止的补货机型，第二年续费政策可能调整，介意的话下单前开工单问清楚。

**只有 IPv4 吗？**
每个套餐带 1 个 IPv4，东京机房的 IPv6 是 /64 地址段（新加坡部分机房是 /112）。有 IPv6 依赖的应用要留意各机房差异。

**买了发现线路不行能退吗？**
不能。特价套餐明确不退款，所以测线路这件事必须放在付款之前，用官方提供的测试 IP 和 Looking Glass 验证你自己的网络。
